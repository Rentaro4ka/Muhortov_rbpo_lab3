Номер студенческого билета: **1БИБ23228**

## Настройка базы данных

Проект использует две роли в PostgreSQL:
1. `db_admin` — администратор (создание таблиц).
2. `app_user` — пользователь приложения (только CRUD, без прав на изменение схемы).

Пароли и логины хранятся в файле ".env".
